# ComPick — фронтенд (прототип интерфейса)

React + TypeScript + Vite + Tailwind. Работает вместе с backend ComPick (FastAPI).

## Запуск (на Mac)

1. Backend (из папки `backend/`):

   ```bash
   uvicorn app.main:app --port 8000
   ```

2. Фронтенд (из папки `frontend/`):

   ```bash
   npm install   # один раз
   npm run dev
   ```

3. Открыть http://localhost:3000

Запросы `/api` и `/health` проксируются на `localhost:8000` (см. `vite.config.ts`).

## Страницы

- `/` — лендинг по макету: назначение + бюджет → кнопка «Собрать ПК» (рекомендация backend материализуется в настоящую сборку через API)
- `/configurator` — конструктор по макету: строки категорий, «Подходит / Не подходит», объяснение причин и совместимые альтернативы, итог по лучшим ценам, панель проверки (сокет, тип памяти, мощность БП), цены магазинов, список для заказа
- `/builds` — готовые сборки по назначению и бюджету
- `/catalog` — каталог комплектующих с фильтрами и предложениями магазинов
- `/stores` — магазины (собираются из живых предложений каталога)

## Особенности прототипа

- Несовместимая деталь не сохраняется в сборке (так устроен backend): она показывается как отклонённая строка с причиной, а альтернативы подбираются пробной установкой кандидатов на одноразовой копии сборки.
- Идентификатор сборки хранится в `sessionStorage` — после перезапуска backend (данные в памяти) сборка пересоздаётся.
